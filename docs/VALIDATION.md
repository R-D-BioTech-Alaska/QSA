# Validation Report — Qubit State Algebra v0.1.2

> Historical report for QSA 0.1.2. The current QSA 0.1.6 release report is in [`VALIDATION_0_1_6.md`](VALIDATION_0_1_6.md).

Validation performed on July 23, 2026 in the supplied Linux build environment.

## Toolchain

- GCC 14.2.0
- CMake
- Python 3.13.5
- NumPy used only as an independent differential reference

## Release compatibility suite

The release build runs five bounded compatibility gates:

1. Native C++ state-engine tests
2. Exported C ABI tests
3. Canonical `qsa` Python tests using `QSA_NATIVE_LIB`
4. Legacy `qubit_native` Python tests using `QUBIT_NATIVE_LIB`
5. Machine-readable QSA 0.1 contract-manifest validation

The native suite now also covers 1,000 independent Bell pairs, inverse-gate
component recovery, stable swap-pop component indexing, and a frozen
multi-component QSC v1 packet whose ordering was generated by QSA 0.1.1.

```text
100% tests passed, 0 tests failed out of 5
```

## Sanitizer validation

The complete native, C ABI, canonical Python, legacy Python, and contract suite
passed with AddressSanitizer and UndefinedBehaviorSanitizer. Leak detection was
enabled for native executables. It was disabled when preloading ASan into the
host Python interpreter because Python and imported host extensions retain
unrelated shutdown allocations.

```text
Sanitized compatibility tests: 5/5 passed
Native ASan/UBSan errors: 0
```

## Differential random-circuit validation

`tests/differential_numpy.py` executes QSA and an independent NumPy statevector
reference side by side.

Validated operations include X, Y, Z, H, S, T, Rx, Ry, Rz, CNOT, CZ, SWAP,
measurement, and collapse.

```text
120 circuits x 120 random gates = 14,400 random gate operations
Differential validation passed: 120 circuits x 120 random gates.
```

Intermediate, final, and post-measurement states use the established
global-phase-invariant fidelity threshold of `2 x 10^-10`.

An additional non-gating stress run completed 300 circuits x 300 gates
(90,000 random operations) with the same comparison rule.

## Frozen persistence contract

Two QSC v1 fixtures are protected:

- Minimal sparse packet
- Multi-component packet exercising merges, swap-pop storage, compaction,
  measurement splitting, rotations, and historical component ordering

Both decode and re-encode byte-for-byte. Constructing the multi-component state
in 0.1.2 also reproduces the packet emitted by 0.1.1.

## Structured-state benchmark

```text
10,000 independent qubits    components=10000  engine-memory=1.07 MiB
50-qubit exact GHZ           components=1      engine-memory=5.83 KiB
100 independent Bell pairs  components=100    engine-memory=26.69 KiB
```

The small increase from 0.1.1 is the four-byte logical-order key per live
component used to preserve QSC ordering while eliminating register-wide hot-path
reindexing.

## Backward wrapper compatibility

The 0.1.2 Python wrapper was loaded against the original 0.1.0 native shared
library. Original gates, ABI 1.0 queries, amplitudes, QSC encode, and QSC decode
passed. Additive 0.1.1/0.1.2 features remain capability-detected rather than
being required from an older library.

## Packaging environment

The installed-layout and native-library tests passed. A wheel was not produced
inside this isolated runner because its package index contains no
`scikit-build-core` distribution. The failure occurred while resolving the
declared build dependency, before QSA compilation. Cross-platform wheel CI
remains the packaging gate.
